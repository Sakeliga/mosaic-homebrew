# Security

Report a suspected vulnerability privately through this repository's
[Report a vulnerability](https://github.com/Sakeliga/mosaic-homebrew/security/advisories/new)
form. Please do not open a public issue with exploit details or credentials.

Reports may cover the Mosaik CLI, its authentication and credential storage,
release downloads and signatures, the Homebrew formula, or the release and
verification process. Include the version, operating system, steps to reproduce
and expected impact. Remove session tokens, API keys and personal data from
examples and logs.

The CLI's source repository is private. You can report a problem here without
access to that repository. Each release publishes the readable JavaScript that
the downloadable binaries contain (`mosaik-<version>.cjs`); its availability
does not grant an open-source licence. See [LICENSE](LICENSE).
